1. Classification

1.1 Experimental Settings

1.1.1 Dataset

The experiments were conducted on a gastrointestinal endoscopic image dataset containing 10,436 images across 16 classes.

The dataset was divided into training and validation sets using an 85:15 stratified split, resulting in 8,870 training images and 1,566 validation images.

All images were resized to 224 × 224 pixels and normalized using ImageNet statistics. Random horizontal flipping was applied during training.

1.1.2 Experimental Configurations

Four experimental settings were evaluated to investigate the effects of backbone initialization strategies and loss functions.

Setting Backbone Initialization Loss Function
1 ImageNet-pretrained ViT-B/16 Cross-Entropy (CE)
2 ImageNet-pretrained ViT-B/16 Evidential Deep Learning (EDL)
3 GastroNet DINOv1-pretrained ViT-B/16 Cross-Entropy (CE)
4 GastroNet DINOv1-pretrained ViT-B/16 Evidential Deep Learning (EDL)

The ImageNet settings used a ViT-B/16 backbone initialized with supervised ImageNet-pretrained weights.

The DINOv1 settings used a ViT-B/16 backbone initialized with weights obtained from self-supervised pretraining on GastroNet images.

For the CE settings, models were optimized using the standard cross-entropy loss. For the EDL settings, a Dirichlet-based evidential loss was used to model classification evidence and estimate predictive uncertainty.

1.1.3 Training Configuration

All ViT models were fine-tuned using the AdamW optimizer with a learning rate of 1 × 10⁻⁴ and a weight decay of 1 × 10⁻⁴.

Training was performed for 15 epochs with a batch size of 512.

The best checkpoint was selected based on the highest validation Macro-F1 score.

The same dataset split and ViT training configuration were used across all four experimental settings to ensure a consistent comparison.
